# Music

Drop Tom's tracks here with these exact names:

- `menu.mp3` — menus, Learning, Stamp Book, results, Zen
- `gameplay.mp3` — Journey and Challenge

MP3, 128–160 kbps, stereo, 1.5–3 minutes, written to loop cleanly (the game loops them).
Until the files exist the game is silent; the toggles still work.
